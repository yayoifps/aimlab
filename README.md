# Cutout Range

キャラクターの切り抜きを的にする、ブラウザで動くエイムトレーナー。

**プレイする → https://yayoifps.github.io/aimlab/**

## 特徴

- **VALORANT と同じ視野角** — 16:9 で水平 103°、垂直 70.5° 固定（Vert−）
- **VALORANT と同じ感度計算** — `0.07°/カウント × 感度`。ゲーム内の数値をそのまま入れて使えます
- **クロスヘア設定** — VALORANT のクロスヘアコードを読み込み／書き出し可能
- **ピクセル単位の当たり判定** — キャラのシルエットだけが命中。背景の透明部分は当たりません
- **タスク: Gridshot** — 格子状に出るキャラを撃ち抜く。60秒
- キャラ別の撃破数、前回スコアとの比較、自己ベスト記録

## 操作

| キー | 動作 |
|---|---|
| マウス | 視点 |
| 左クリック | 射撃 |
| `F` | 全画面 |
| `Esc` | 中断 |
| `R` | リスタート |

ブラウザがマウスを画面に固定できない環境（埋め込み枠内など）では、
カーソル位置で視点が回る「簡易FPS視点」に自動で切り替わります。
本来の振り向き感度で遊ぶには全画面推奨です。

## キャラクターの追加・変更

`src/` に透過 PNG を置いてビルドスクリプトを実行すると、`index.html` に焼き込まれます。

```
src/
  01.png      立ちポーズ（的として出現）
  01_1.png    撃たれたときのポーズ（任意）
  02.png / 02_1.png ...
  names.json  リザルト画面に出す表示名
```

```bash
py build_sprites.py
```

`names.json`:

```json
{
  "01": "izumii",
  "02": "kun"
}
```

撃たれポーズは立ちポーズと同じ縮小率で処理されるので、姿勢が変わっても体格が揃います。

## 構成

`index.html` は画像を base64 で内包した**単一ファイル**です。外部リソースは Google Fonts のみ
（読めない環境ではシステムフォントにフォールバックします）。サーバー不要で、
ファイルをダブルクリックするだけでも動きます。

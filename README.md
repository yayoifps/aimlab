# Cutout Range

キャラクターの切り抜きを的にする、ブラウザで動くエイムトレーナー。

**プレイする → https://yayoifps.github.io/aimlab/**

## 特徴

- **VALORANT と同じ視野角** — 16:9 で水平 103°、垂直 70.5° 固定（Vert−）
- **VALORANT と同じ感度計算** — `0.07°/カウント × 感度`。ゲーム内の数値をそのまま入れて使えます
- **クロスヘア設定** — VALORANT のクロスヘアコードを読み込み／書き出し可能
- **ピクセル単位の当たり判定** — キャラのシルエットだけが命中。背景の透明部分は当たりません
- キャラ別の撃破数、前回スコアとの比較、自己ベスト記録
- タスクごとの目標命中率（既定 97%）。達成すると緑で表示
- 撃破時、的が破片になって飛び散る（UNDERTALE のハートが砕けるイメージ）
- キャラごとの撃破ボイス。同じキャラに複数あれば毎回ランダムで再生
- 背景色を自由に変更でき、床・壁・的の縁取りの明暗が自動で追随する

## タスク（各30秒）

**Gridshot** — 格子状のセルにキャラが出現。撃つと即座に別のセルへ再出現する。
撃つ前に次の的へ視線を送り、照準はあとから運ぶ——目の使い方をつくるタスクで、
エイムのウォーミングアップ向き。

**Ohki Aim（左右から出現）** — 待ちのエイムを鍛えるタスク。的が出てくる角に
あらかじめ照準を置き、姿が見えた瞬間に撃つ。見えてから動かしていては間に合わない。

左右に立つ壁の陰から的が現れ、一定速度で横切る。4秒ごとに出てくる側が右→左と入れ替わり、
次に出る側の壁には矢印が出る。倒すか、倒しそこねて反対側の壁に入った時点で次が出る。
速度は VALORANT 準拠（走り 6.75 m/s ・ 歩き 3.4 m/s）に倍率をかけたもの。

壁は的と同じ奥行きに置いた実際の遮蔽物で、裏にいる的は見えないし撃てない。
角から半分だけ出ている間は、**はみ出した部分だけが当たり判定を持つ**。
的が隠れている間は、次に出てくる側の壁に矢印が出る。

「出てくるまでの間」は距離ではなく時間で指定するので、走りでも歩きでも
倒してから次が姿を現すまでの間隔は同じになる。
切替間隔・壁の間隔・距離・速度倍率も設定で変更できる。

## 操作

| キー | 動作 |
|---|---|
| マウス | 視点 |
| 左クリック | 射撃 |
| `F` | 全画面 |
| `Esc` | 中断 |
| `R` | リスタート |

ブラウザがマウスを画面に固定できない環境（埋め込み枠内など）では、
カーソル位置で視点が回る「簡易FPS視点」に自動で切り替わります。
本来の振り向き感度で遊ぶには全画面推奨です。

## キャラクターの追加・変更

`src/` に透過 PNG を置いてビルドスクリプトを実行すると、`index.html` に焼き込まれます。

```
src/
  01.png      立ちポーズ（的として出現）
  01_1.png    撃たれたときのポーズ（任意）
  02.png / 02_1.png ...
  names.json  リザルト画面に出す表示名
  voice/      撃破時のボイス（任意）
    01-1.mp3  01-2.mp3    ← 01 を倒すとこの中からランダム
    02-1.mp3  02-2.mp3
```

```bash
py build_sprites.py
```

`names.json`:

```json
{
  "01": "izumii",
  "02": "kun"
}
```

撃たれポーズは立ちポーズと同じ縮小率で処理されるので、姿勢が変わっても体格が揃います。

## 構成

`index.html` は画像を base64 で内包した**単一ファイル**です。外部リソースは Google Fonts のみ
（読めない環境ではシステムフォントにフォールバックします）。サーバー不要で、
ファイルをダブルクリックするだけでも動きます。
